# 📦 ✅ OS-Personnel
   - — Version 1.0.0

- Système d’exploitation minimaliste conçu pour une mission unique :
   - Fournir une base stable, sécurisée et modulaire pour exécuter un service principal en conteneur.

### 🎯 Objectifs
- OS minimal basé sur Buildroot
- Rootfs en lecture seule (SquashFS)
- Partition /data persistante
- Docker comme moteur de conteneurs
- Architecture simple, évolutive
